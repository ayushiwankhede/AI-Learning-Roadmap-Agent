# Sample Roadmap: Learn Python in 30 Days

> Illustrative example for a beginner studying around 3–5 hours per week. This is a sample document, not an output captured from a live workflow run.

## Goal
Build a foundation in Python and finish the month with a small project that demonstrates variables, control flow, functions, collections, and basic file handling.

## The big picture
Python is useful for automation, data analysis, web development, and AI. Thirty days can build beginner confidence and support a small project, but it is not a guarantee of mastery or job readiness.

## Core skills
- **Syntax and variables:** store and work with information.
- **Conditions and loops:** make programs respond and repeat tasks.
- **Functions:** organize code into reusable pieces.
- **Collections:** use lists and dictionaries.
- **Files and debugging:** save information and investigate errors.

## 30-day kickstart plan

### Week 1 — Foundations
- Install Python and choose an editor such as VS Code.
- Learn variables, strings, numbers, input/output, and operators.
- Practice with a unit converter or simple bill calculator.
- **Milestone:** write a program that accepts input and prints a useful result.

### Week 2 — Logic and collections
- Learn `if`/`elif`/`else`, `for` and `while` loops.
- Practice with lists and dictionaries.
- Build a number-guessing game or quiz.
- **Milestone:** solve small problems without copying a full solution.

### Week 3 — Functions and files
- Break a program into functions.
- Learn basic file reading and writing.
- Add handling for common invalid inputs.
- **Milestone:** build a small expense tracker or task list that saves data.

### Week 4 — Project and review
- Choose a small project and define its features.
- Build, test, and fix bugs.
- Write a README explaining how to run it.
- **Milestone:** publish the project on GitHub.

## Suggested weekly routine
For 3–5 hours per week, try three or four short sessions:
1. Learn one concept for 20–30 minutes.
2. Spend 30–45 minutes writing code yourself.
3. Review errors and note what you learned.
4. Combine the concepts in a mini-project at the end of the week.

## Starter toolkit
- **Python:** language runtime.
- **VS Code:** code editor.
- **Official Python tutorial:** reference alongside practice.
- **GitHub:** store your project and explain what you built.

## Progress milestones
- A calculator or unit converter.
- A quiz or number-guessing game.
- A file-based task list or expense tracker.
- A GitHub repository with working code and setup instructions.

## Common mistakes to avoid
- Watching tutorials without writing code.
- Copying solutions before attempting the problem.
- Starting a large project before learning the basics.
- Treating a 30-day plan as a guarantee of job readiness.

## First three steps
1. Install Python and verify that it runs.
2. Write a program that asks for your name and prints a greeting.
3. Create a folder for exercises and record your progress.
